# Tavern Coin Flip Game

A fun, tavern-themed coin flip game with a beautiful background image and interactive gameplay.

## Features

- **Tavern-themed Background**: Uses the provided tavern image as the game's atmospheric background
- **Interactive Coin Flip**: Animated 3D coin flip with heads/tails outcomes
- **Score Tracking**: Keeps track of wins and losses
- **Keyboard Shortcuts**: 
  - Press 'H' for Heads
  - Press 'T' for Tails
  - Press Space or Enter to flip the coin
- **Responsive Design**: Works on desktop and mobile devices
- **Beautiful Animations**: Smooth coin flip animation with 3D effects

## How to Play

1. Open `index.html` in your web browser
2. Choose either "Heads" or "Tails" by clicking the buttons
3. Click "Flip the Coin!" to see the result
4. Watch your win/loss statistics update automatically
5. Play again immediately after each round

## Files

- `index.html` - Main game page
- `style.css` - Styling with tavern background integration
- `script.js` - Game logic and interactions
- `tavern image.png` - Background image for the game

## Game Design

The game features a medieval tavern atmosphere with:
- Gold and bronze color scheme
- Semi-transparent game container overlaid on the tavern background
- Realistic coin animation
- Win/loss feedback with appropriate colors and emojis

Enjoy testing your luck in the tavern!
