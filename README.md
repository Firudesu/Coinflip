# 🎮 Pixel Coin Flip Streak Game

A retro-style coin flipping game with streak mechanics and score multipliers, designed with 16-bit pixel aesthetics.

## 🎯 How to Play

1. **Make Your Guess**: Click either "HEADS" or "TAILS" to make your prediction
2. **Flip the Coin**: Click the "FLIP THE COIN!" button to flip
3. **Build Streaks**: Correct guesses build your streak and increase your multiplier
4. **Track Progress**: Watch your current streak, multiplier, and best streak

## 🔥 Game Features

- **Streak System**: Each correct guess increases your streak counter
- **Score Multiplier**: Starts at 1.0x, increases by 0.1x for each correct guess
- **Best Streak Tracking**: Your highest streak is saved locally
- **Pixel Art Style**: Retro 16-bit graphics with authentic pixel fonts
- **Animated Coin**: Smooth 3D coin flip animations
- **Visual Effects**: Particle effects, glowing borders, and screen shake
- **Responsive Design**: Works on desktop and mobile devices

## 🎨 Visual Features

- **Retro Color Palette**: Authentic 16-bit colors (greens, cyans, yellows)
- **Pixel Perfect Font**: "Press Start 2P" Google Font for authentic feel
- **Animated Elements**: Glowing text, pulsing buttons, and smooth transitions
- **Special Effects**: Success/failure visual feedback with border colors
- **Particle System**: Celebratory particles during coin flips

## 🚀 Getting Started

Simply open `index.html` in any modern web browser to start playing!

## 🛠️ Technical Details

- **Pure HTML/CSS/JavaScript**: No frameworks or dependencies
- **Local Storage**: Best streak is automatically saved
- **CSS Animations**: Smooth 60fps animations using CSS transforms
- **Responsive**: Mobile-friendly design with touch support
- **Cross-Browser**: Compatible with all modern browsers

## 🎮 Controls

- **Mouse/Touch**: Click buttons to select heads/tails and flip coin
- **Keyboard**: Press Ctrl+C to see developer info in console

## 📱 Mobile Support

The game is fully responsive and works great on mobile devices with touch controls.
